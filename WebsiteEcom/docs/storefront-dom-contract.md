# Storefront DOM contract

**Deliverable named by ADR-018 D1 §SEO integration points** ("DOM contract additions").
This is the authoritative list of every `data-testid` attribute rendered by the storefront
templates (`storefront/templates/storefront/**/*.html`) — the stable hooks that end-to-end
tests, the Designer agent, and the Spec Reviewer agent rely on instead of CSS classes or
DOM structure (which theme work is free to change).

**Rule:** a `data-testid` is a contract. Renaming or removing one is a breaking change for
whatever test/tooling depends on it — treat it the same as a public API rename. Adding a new
one for a genuinely new interactive element is always safe.

Generated by grepping `data-testid="..."` across `storefront/templates/`. Regenerate this
table (or at least spot-check it) whenever a template adds/removes a `data-testid`.
